# CCE II - Git and GitHub Repository
## Unit IV: Stacks and Queues

### 📌 Project Objective
This repository is created and maintained as part of the CCE II activity to implement data structures related to Stacks and Queues using C++. It demonstrates the practical application of linear data structures, version control using Git, and proper repository documentation.

### 📁 Programs Included
* **stack2.cpp**: Implementation of Stack data structure operations (Push, Pop, Peek).
* **queue.cpp**: Implementation of Queue data structure operations (Enqueue, Dequeue).
* **postfix.cpp**: Program for the evaluation or conversion of Postfix expressions using Stacks.
* **double_linklist.cpp**: Implementation of Doubly Linked List.

### 🛠️ Technology Used
* **Language**: C++
* **Version Control**: Git & GitHub
